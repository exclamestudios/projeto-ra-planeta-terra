# Projeto RA Planeta Terra

Projeto de Realidade Aumentada que permite visualizar o planeta Terra em 3D através de um marcador.

## Tecnologias Utilizadas

- Three.js para renderização 3D
- MindAR para realidade aumentada
- HTML5 e JavaScript

## Como Usar

1. Acesse o site: [https://planeta-terra-ar.onrender.com](https://planeta-terra-ar.onrender.com)
2. Clique no botão "Iniciar Realidade Aumentada"
3. Permita o acesso à câmera
4. Apresente o marcador (imagem da Terra) à câmera
5. O modelo 3D do planeta Terra aparecerá sobre o marcador

## Desenvolvimento

Para executar localmente:

1. Clone o repositório:
```bash
git clone https://github.com/exclamestudios/projeto-ra-planeta-terra.git
```

2. Abra o arquivo `index.html` em um servidor local

## Estrutura do Projeto

- `index.html` - Página principal
- `main.js` - Lógica da aplicação
- `mind/` - Arquivos do MindAR
- `img/` - Imagens do projeto
- `lib/` - Bibliotecas externas
